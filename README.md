# EdgeVision

Distributed Edge AI Video Analytics Platform.

## Overview

EdgeVision is a distributed platform for processing live and recorded video streams using OpenVINO-optimised AI models.

The platform consists of:

- C++ Video Streaming Service
- Kafka Event Pipeline
- Python Inference Workers
- PostgreSQL Storage
- MinIO Object Storage
- FastAPI Gateway
- React Dashboard

## Supported Domains

- Traffic Analytics
- Retail Analytics
- Warehouse Analytics
- Hospital Analytics
